# Greenside - Energía Solar & Futuro Sostenible ☀️🌱

> **Greenside** es una plataforma y empresa de soluciones energéticas renovables nacida en Mendoza, Argentina. Fundada por **Agustín Vaca Cornejo**, un joven emprendedor cuyano enfocado en revolucionar el acceso a la energía limpia a través de la tecnología y la ingeniería de vanguardia.

---

## 🚀 Características de la Landing Page

- 🌟 **Identidad de Marca**: Integración del logo oficial de Greenside y estética moderna dark mode con acentos esmeralda y solares.
- 📖 **Sección Storytelling / Misión**: La historia y visión de Agustín Vaca Cornejo, con enfoque en el desarrollo productivo y sustentable de Mendoza.
- 🧮 **Calculadora de Ahorro Solar Interactiva**: Permite a usuarios residenciales, comerciales y agrícolas calcular su ahorro mensual, anual y reducción de huella de CO₂.
- ⚡ **Servicios Integrales**: Cobertura para Residencial, Comercial e Industrial, y Agro / Bombeo solar.
- 🛠️ **Proceso de 4 Pasos & Garantías**: Transparencia técnica, componentes Tier-1 y soporte en el marco de la Ley de Generación Distribuida (Ley 27.424).
- 💬 **Conversión Directa**: Formulario y botón flotante integrados directamente con WhatsApp.
- ⚡ **Tecnologías**: React 19, TypeScript, Vite, Tailwind CSS v4, Lucide Icons.

## 🛠️ Instalación y Desarrollo Local

1. Clona el repositorio:
   ```bash
   git clone https://github.com/maximoGs/GreensideWeb.git
   cd GreensideWeb
   ```

2. Instala las dependencias:
   ```bash
   npm install
   ```

3. Inicia el servidor de desarrollo:
   ```bash
   npm run dev
   ```

4. Compila para producción:
   ```bash
   npm run build
   ```
